# План тестирования ToDoList

## 1. Информация о проекте
- **Проект:** ToDoList Web Application
- **Версия:** 1.0
- **Статус:** Черновик/Утверждено

## 2. Цели тестирования
- Проверить корректную работу всех функциональных требований:
  - Регистрация и аутентификация пользователей
  - Создание, редактирование, удаление задач
  - Управление группами задач
  - Просмотр и фильтрация задач
- Проверить нефункциональные требования:
  - Производительность API
  - Безопасность (аутентификация, авторизация)
  - Юзабилити веб-интерфейса
- Проверить интеграцию между контроллерами, сервисами и базой данных
- Обеспечить целостность данных

## 3. Область тестирования
### Включено
- Пользовательский модуль (регистрация, логин, профиль)
- Управление задачами (CRUD)
- Управление группами задач
- Фильтрация и сортировка задач
- Валидация данных
- Интеграция с базой данных
- REST API
- Unit-тесты для сервисов (TaskService, UserService, GroupService)
- Нагрузочное тестирование API (JMeter)

### Исключено
- Email уведомления
- Интеграция с внешними сервисами
- Мобильное приложение (только веб)

## 4. Стратегия тестирования
- **Unit Testing:** тестирование отдельных сервисов и контроллеров (JUnit 5 + Mockito)
- **Integration Testing:** проверка взаимодействия API с базой данных
- **System Testing:** проверка полного рабочего сценария (создание и управление задачами)
- **Performance Testing:** нагрузочное тестирование основных API с JMeter
- **Security Testing:** тестирование аутентификации и авторизации

## 5. Среда тестирования
- **Backend:** Java 17, Spring Boot, Maven
- **Database:** PostgreSQL 15
- **Frontend:** любой современный браузер
- **Инструменты:** JUnit 5, Mockito, Postman, JMeter

## 6. Тестовые данные
- Несколько пользователей с разными ролями
- Разные группы задач
- Задачи с разными датами, приоритетами и статусами
- Граничные значения (пустые поля, длинные тексты, спецсимволы)

## 7. Критерии успешности
- Все критические функции работают корректно
- Unit-тесты сервисов успешно пройдены
- API отвечает за <1 секунду на стандартные запросы в нагрузочном тестировании
- Нет потерь данных при CRUD операциях
- Аутентификация и авторизация защищены
