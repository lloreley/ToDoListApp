# ToDoList — Глоссарий ключевых терминов
## Пользователь (User)

Зарегистрированное лицо, использующее систему ToDoList для создания, просмотра и управления личными или групповыми задачами.

## Администратор (Administrator)

Пользователь с расширенными правами, управляющий другими пользователями, группами и системными настройками.

## Задача (Task)

Элемент, представляющий действие или цель, которую необходимо выполнить. Может содержать приоритет, статус, комментарии, теги и вложения.

## Группа (Group)

Объединение пользователей для совместной работы над задачами.

## Роль в системе (Role)

Определяет тип и уровень полномочий пользователя во всей системе (администратор системы, обычный пользователь).

## Приоритет (Priority)

Показатель важности или срочности задачи (низкий, средний, высокий, критический).

## Комментарий (Comment)

Текстовое сообщение, добавленное пользователем к задаче для уточнения информации или обсуждения.

## Назначение (Assignment)

Связь между задачей и пользователем, отвечающим за её выполнение.

## Статус задачи (TaskStatus)

Текущее состояние задачи («в работе», «выполнена»).

## JWT (JSON Web Token)

Компактный токен, используемый для аутентификации и подтверждения личности пользователя при обращении к API.

## CRUD

Набор базовых операций над данными: Create, Read, Update, Delete (создание, чтение, обновление, удаление).

## REST API

Интерфейс взаимодействия фронтенда и бэкенда через HTTP-запросы, основанный на принципах REST.

## PostgreSQL

Реляционная база данных, используемая для хранения информации о пользователях, задачах, группах и связанных сущностях.

## Spring Boot

Java-фреймворк, применяемый для разработки серверной части приложения и реализации REST API.

## React

JavaScript-библиотека для построения клиентского интерфейса приложения.

## Frontend (Фронтенд)

Клиентская часть системы, с которой пользователь взаимодействует напрямую.

## Backend (Бэкенд)

Серверная часть системы, обрабатывающая запросы, выполняющая бизнес-логику и взаимодействующая с базой данных.
