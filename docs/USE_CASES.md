# Use Case Диаграмма — Система ToDoList

Этот документ описывает актёров и варианты использования (Use Cases) в системе **ToDoList**.  
Материал служит основой для анализа требований и проектирования пользовательского поведения.

---

# Актёры системы

| Актёр | Описание |
|-------|----------|
| **User** | Обычный пользователь, использующий систему для управления своими личными и групповыми задачами. |
| **Admin** | Администратор системы. Имеет дополнительные права и управляет данными. |
| **Auth Service (JWT)** | Сервис аутентификации, который выполняет регистрацию, вход и выдаёт JWT-токены. |

---

# Основные варианты использования (Use Cases)

| Код | Название | Краткое описание |
|-----|----------|------------------|
| **UC1** | Register | Регистрация нового пользователя через Auth Service. |
| **UC2** | Login | Вход пользователя в систему и получение JWT. |
| **UC3** | Create Task | Создание новой личной задачи. |
| **UC4** | Edit Task | Редактирование существующей задачи. |
| **UC5** | Delete Task | Удаление задачи. |
| **UC6** | Mark as Done | Отметить задачу как выполненную или невыполненную. |
| **UC7** | View Tasks | Просмотр всех личных задач. |
| **UC8** | Create Group | Создание новой группы задач. |
| **UC9** | Invite User | Приглашение пользователей в группу. |
| **UC10** | Assign Task | Назначение групповой задачи участнику группы. |
| **UC11** | Manage Users | Управление списком пользователей, задча, групп (Admin). |
| **UC12** | Assign Roles | Назначение ролей пользователям (Admin). |

---

# Связи между актёрами и вариантами использования

### User
Пользователь выполняет следующие варианты использования:

**UC1 — UC11**

То есть:
- регистрация  
- вход  
- управление личными задачами (создание, редактирование, удаление, просмотр)  
- управление групповыми задачами  
- участие в группах  

---

### Admin
Admin может выполнять:

**UC11 — UC2**

- управление всеми пользователями, задачами, группами 
- изменять роли  

---

### Auth Service (JWT)
Обеспечивает выполнение внутренних операций:

- Обработка данных при регистрации (**UC1**)  
- Проверка логина и пароля (**UC2**)  
- Генерация JWT-токена
